# Cheesecake School — Roadmap

## Статус сейчас

На текущий момент в проекте реализованы:
- Аутентификация (логин/регистрация/восстановление пароля)
- Обновленный Topbar и ProtectedRoute с корректной обработкой состояний
- Страница преподавателей (/teachers) с корректной работой
- Исправлены проблемы с бесконечными загрузками

Требуют доработки:
- Админ-панель (необходимо расширить функционал)
- Система ролей (требуется полная реализация разграничения доступа)

## Роли и доступы

В системе предусмотрены следующие роли:
- **student** — базовая роль для учеников
- **teacher** — роль преподавателя с расширенными возможностями
- **admin** — роль администратора с полным доступом

Разграничение доступа:
- Доступ к `/admin` имеют только пользователи с ролью **admin**
- Материалы и домашние задания доступны ученикам только после назначения преподавателя
- Преподаватели имеют доступ к информации только о своих учениках

## Архитектура данных

### Таблицы

#### users
- `id` — уникальный идентификатор (UUID)
- `email` — email пользователя
- `created_at` — дата создания
- `role` — роль пользователя (student, teacher, admin)

#### students
- `id` — уникальный идентификатор
- `user_id` — связь с таблицей users
- `display_name` — отображаемое имя
- `subscription_end` — дата окончания абонемента
- `lessons_left` — количество оставшихся занятий
- `teacher_id` — связь с таблицей teachers (назначенный преподаватель)

#### teachers
- `id` — уникальный идентификатор
- `user_id` — связь с таблицей users
- `display_name` — отображаемое имя
- `bio` — информация о преподавателе
- `specialization` — специализация

#### lessons
- `id` — уникальный идентификатор
- `title` — название занятия
- `teacher_id` — связь с таблицей teachers
- `student_id` — связь с таблицей students
- `start_at` — дата и время начала
- `duration` — продолжительность в минутах
- `status` — статус (planned, done, canceled)
- `class_name` — название класса/группы
- `notes` — заметки к занятию

#### materials
- `id` — уникальный идентификатор
- `title` — название материала
- `description` — описание
- `file_path` — путь к файлу в storage
- `teacher_id` — связь с таблицей teachers (автор)
- `class_name` — для какого класса/уровня
- `created_at` — дата создания

#### homework
- `id` — уникальный идентификатор
- `title` — название задания
- `description` — описание
- `student_id` — связь с таблицей students
- `teacher_id` — связь с таблицей teachers
- `lesson_id` — связь с таблицей lessons
- `status` — статус (assigned, submitted, reviewed)
- `submission_path` — путь к файлу с решением
- `feedback` — обратная связь от преподавателя
- `grade` — оценка

## Гайд по сборке и деплою

### Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev
```

### Сборка проекта

```bash
# Сборка для production
npm run build
```

### Деплой на Netlify

1. Подключите репозиторий к Netlify
2. Настройте команду сборки: `npm run build`
3. Укажите директорию публикации: `dist`
4. Добавьте необходимые переменные окружения

### Переменные окружения

Для работы приложения необходимо настроить следующие переменные:

```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```
